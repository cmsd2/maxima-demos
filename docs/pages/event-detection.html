Event Detection with CVODE¶

SUNDIALS CVODE includes a rootfinding feature: given event functions $g_i(t, y)$, the solver detects zero crossings to high accuracy without requiring the user to manually bracket or bisect.

Pass events as the 8th argument in expression mode:

np_cvode(rhs, vars, y0, tspan, rtol, atol, method, [g1, g2, ...])

When events are present, np_cvode returns [trajectory, events_list] where each event is [t_event, [y_values], [indices], [directions]]. The directions entries are +1 for rising crossings and -1 for falling, in the same order as the indices.

A 10th argument rootdir (one of -1, 0, +1 per event) lets you restrict detection to a single direction — useful when a post-event reset leaves the state exactly on the boundary and you want to suppress the immediate re-trigger.

2. Bouncing Ball — Multiple Bounces¶

To simulate repeated bounces, we use the stateful API: np_cvode_create builds a persistent integrator, np_cvode_step advances it segment-by-segment, and np_cvode_reinit resets the state after each impact (reversing the velocity with coefficient of restitution $e = 0.8$). Reusing one handle across all bounces avoids the cost of rebuilding the linear solver and re-registering events on each segment.

We also pass rootdir = [-1] so CVODE only detects falling crossings of $h$. Without this, the post-bounce state $h = 0,\ v > 0$ sits exactly on the event surface and would re-trigger immediately.

/* Multi-bounce via stateful CVODE handle.
   rootdir = [-1] only fires on falling crossings of bh, so the post-bounce
   state (bh = 0, bv > 0) doesn't immediately re-trigger the root. */
cor : 0.8$
t_end : 8.0$
dt : 0.01$

t_all : [0.0]$  h_all : [10.0]$  v_all : [0.0]$
event_times : []$

solver : np_cvode_create([bv, -g], [bt, bh, bv],
                         [10.0, 0.0], 0.0,
                         1e-12, 1e-12, adams, [bh], 5000, [-1])$

t_now : 0.0$
while t_now < t_end do block([res, ev],
  res : np_cvode_step(solver, min(t_now + dt, t_end)),
  if length(res[3]) > 0 then (
    /* An event fired during this step.  Record the event point and
       reinit; the integrator continued past the event to res[1]
       without knowing about the bounce, so we discard that state. */
    ev : first(res[3]),
    event_times : endcons(ev[1], event_times),
    t_now : ev[1],
    t_all : endcons(ev[1], t_all),
    h_all : endcons(ev[2][1], h_all),
    v_all : endcons(ev[2][2], v_all),
    np_cvode_reinit(solver, ev[1], [0.0, -cor * ev[2][2]])
  ) else (
    t_now : res[1],
    t_all : endcons(res[1], t_all),
    h_all : endcons(res[2][1], h_all),
    v_all : endcons(res[2][2], v_all)
  )
)$

3. Projectile with Drag — Target Altitude¶

A projectile launched upward with quadratic air drag: $$\dot{h} = v, \quad \dot{v} = -g - \frac{\rho\,C_d\,A}{2m}\,v\,|v|$$

Events: detect when the projectile crosses $h = 50\,$m (ascending and descending).

Event: $\theta = 0$ (each time the pendulum passes through the vertical). We detect all zero-crossings and measure the decaying amplitude.
